# 卡片自适应黄金比例网格布局 + 整卡点击启动 + 主题与细节对齐顶级软件设计

## Goal

前端布局升级:卡片按窗口实时尺寸自适应、多列多行、黄金比例美学;卡片除语义按钮外整卡可点击启动;日夜模式与整体细节对齐顶级软件设计。

## Background(现状,2026-08-01)

- 网格当前为单列滚动列表:`App.css` `.item-grid` 是 `flex-direction: column`,卡片全宽,`overflow-y: auto`(App.css:55-62)。
- 整卡点击目前只覆盖 `.card-main`(标题/目录/命令,ItemCard.tsx:34-51),checkbox 与 4 个操作按钮(上移/下移/编辑/删除)为独立语义区域。
- 主题已有三态:`settings.theme`(light / dark / system)→ `applyTheme` 设 `data-theme` → CSS 变量(`App.css:356-404`),system 走 `@media (prefers-color-scheme)`。
- 已有主题过渡动画(`App.css:517-524`)、搜索匹配高亮、危险命令三处警示、双击防抖、模态框 Enter 确认、状态栏自动消失、空态图标、关于对话框、窗口最小尺寸等打磨(见 git ef2b121 / c940ed7 / bbc11bb)。
- 前端栈:React 19 + Vite 7 + Zustand + lucide;Tauri 2 窗口最小尺寸 480x360(tauri.conf.json)。

## Requirements

- R1(已确认):网格"缩放适配 + 最小尺寸兜底"——窗口 resize 时行列数/卡片尺寸实时重算、全部卡片可见;卡片窄到低于最小可读宽度(约 240px)时停止缩放并出现滚动条。
- R2(已确认):黄金比例用于列数计算——枚举列数使卡片宽高比最接近 1.618(网格整体宽高比随之趋近 φ)。
- R3(已确认):整卡点击启动——卡片除 checkbox 与 4 个操作按钮(上移/下移/编辑/删除)外,整卡(含 padding 区域)单击即可启动;危险确认与双击防抖逻辑沿用现有链路。
- R4(已确认):日夜模式视觉质量全面升级,以 Windows 11 Fluent 为标杆——语义色分层体系、深浅各自调校、文本分级、WCAG AA 对比度、全组件动效一致、细节打磨(滚动条/选中态/禁用态/焦点环)。
- R5(已确认):全应用打磨——顶栏/统计栏/状态栏/全部对话框(编辑/删除/确认/关于)/空态统一按顶级标准打磨,建立 4/8px 间距体系、圆角/阴影层级、焦点环与禁用态一致性。

## Technical Notes

- 布局算法:JS 枚举列数 c ∈ [1, N],r = ceil(N/c),w = (W-gap·(c-1))/c,h = (H-gap·(r-1))/r,选 |w/h - φ| 最小且 w ≥ minW 的 c;无解(全不满足 w ≥ minW)则进入滚动兜底:列数 = max(1, floor((W+gap)/(minW+gap))),垂直滚动。
- 实现:纯函数 `planGrid(W, H, N, minW)` 可单测;React 侧 `useLayoutEffect` + resize 监听(防抖约 100ms);CSS Grid `repeat(c, 1fr)`。
- 主题:CSS 变量分层重构,深浅两套 token;过渡动画统一。
