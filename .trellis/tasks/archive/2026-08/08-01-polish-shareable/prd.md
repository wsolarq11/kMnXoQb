# 产品打磨至拿得出手（拿给最好的朋友用的标准）

## Goal

以"拿给最好的朋友用，拿出手时充满自豪"为标准持续迭代。当前（2026-08-01 盘点）存在 3 个功能缺陷 + 3 项体验缺失 + 3 项外观差距，逐轮修复并验证，直到达到标准。

## 差距清单（诚实盘点）

### 功能缺陷（必修）
- F1 主题三态切换不生效：settings.theme 已存盘，但 CSS 只响应 prefers-color-scheme，点击按钮 UI 不变
- F2 单实例缺失：双开产生多窗口（设计 D7 未实施）
- F3 窗口状态不保存：save_window_state 命令存在但 close 事件未接线，重启位置重置

### 体验缺失
- E1 无键盘操作：Enter 启动聚焦卡片、Esc 关闭对话框、Ctrl+F 聚焦搜索
- E2 冷启动 35s 无加载反馈：启动即白屏，朋友会以为卡死（需加载态/启动提示）
- E3 无版本信息

### 外观差距
- V1 界面朴素：无阴影/过渡/现代间距
- V2 深色模式未配套三态主题
- V3 窗口图标是 Tauri 脚手架默认
